## 1. Executive Summary

AssistAI is a backend-first product whose single differentiator is: **generate low-latency inline text completions grounded in the user's own corpus**.

The MVP targets Spanish-speaking legal professionals who need to draft long-form, domain-specific documents. Instead of searching past documents manually or using generic AI copilots that lack context, users get inline suggestions grounded in their own Google Drive files.

### Success Metrics

| Metric | Target |
|--------|--------|
| Activation | Users can connect Drive, index content, and receive completions within 48 hours |
| Trust | Suggestions include visible source evidence |
| Latency | Median completion < 1.5s, p95 < 3s |
| Retention | Weekly active writers meet 50%+ target |

---

## 2. Target Audience

### Primary Persona

- **Role**: Lawyers and legal professionals in Spanish-speaking LATAM
- **Pain Point**: Time wasted searching past documents, reusing preferred language, validating phrasing
- **Need**: Fast, trustworthy suggestions grounded in their own corpus

### Secondary Personas (Post-MVP)

- Journalists
- Public administration staff

---

## 3. MVP Scope

### Must Have (P0)

| Feature | Description |
|---------|-------------|
| Web editor | Tiptap-based editor with inline ghost-text suggestions |
| Tab-to-accept | Keyboard interaction to accept suggestions |
| User accounts | Magic-link authentication |
| Single-user workspace | One workspace per user |
| Google Drive connection | OAuth flow, file/folder selection |
| Document ingestion | TXT, Markdown, DOCX, text-based PDFs |
| Retrieval-augmented completion | Pipeline that grounds suggestions in user documents |
| Evidence panel | Shows top retrieved references behind each suggestion |
| Model configuration | BYO endpoint OR OpenRouter-managed inference |
| Spanish-first UX | All UI and error states in Spanish |
| Instrumentation | Usage logs, latency tracking, completion acceptance |

### Should Have (P1 — If On Track)

- IPFS manual import by CID
- Re-index action per source
- Basic document library
- Legal-oriented prompt presets in Spanish

### Explicitly Out of Scope

- Real-time collaboration
- Side chat / agents
- Fine-tuning
- Team permissions / Enterprise RBAC
- SSO, SCIM, team billing
- OCR-heavy workflows / scanned PDFs
- Continuous Drive sync
- Mobile app

## 4. Technical Constraints (Locked)

| Constraint | Value |
|------------|-------|
| Embedding model | `text-embedding-3-small` with `dimensions: 1024` |
| Vector column | `vector(1024)` |
| Chunking | `RecursiveCharacterTextSplitter`, 1500 chars, 200 overlap |
| Retrieval top-k | 4 chunks |
| Confidence threshold | cosine similarity ≥ 0.72 |
| pgvector index | HNSW: m=16, ef_construction=64 |
| Session cookie | `__Host-` prefix, `HttpOnly; Secure; SameSite=Lax`, 8h rolling |
| Auth rate limit | 5 req / 15 min per IP |
| Completion rate limit | 60 req/min + 1000/day per user |

## 5. User Flows

### Flow 1: Sign Up & Onboarding

1. User visits app → Login page
2. Enters email → Magic link sent via Resend
3. Clicks magic link → Verified, workspace created
4. Redirected to Dashboard

### Flow 2: Connect Source

1. User clicks "Conectar Google Drive"
2. OAuth flow redirects to Google
3. User grants permissions
4. File picker opens → User selects files/folders
5. Files added to source list → Indexing starts

### Flow 3: Get Completion

1. User opens Editor
2. Types text → Debounce triggers completion request
3. Backend: retrieval → prompt assembly → LLM call → streaming response
4. Ghost text appears inline
5. User presses Tab → Text accepted, logged for analytics

## 6. Beta Readiness Criteria

The MVP is beta-ready when ALL of the following are true:

1. ✅ User can sign up, connect Google Drive, select files, and complete indexing without manual engineering support
2. ✅ Editor can show grounded inline completions in Spanish
3. ✅ Median completion latency < 1.5s, p95 < 3s for managed path
4. ✅ Suggestions include evidence visibility for the user
5. ✅ BYO model endpoint setup works for defined compatibility contract
6. ✅ Security baseline controls for sessions, secrets, tenant isolation, and SSRF protections are in place
7. ✅ Instrumentation exists for activation, suggestion acceptance, source inspection, and failure rates
8. ✅ At least one retention metric has baseline value captured from beta cohort
